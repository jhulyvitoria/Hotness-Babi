# Hotness da Babi — arquivos do site

Projeto em HTML, CSS e JavaScript.

## Abrir no VS Code

1. Extraia o arquivo ZIP.
2. No VS Code, escolha **Arquivo > Abrir Pasta** e selecione a pasta `hotness-da-babi-vscode`.
3. Abra `index.html`. Para visualizar, use a extensão **Live Server** ou abra o arquivo no navegador.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: cores, layout e versão para celular.
- `script.js`: troca de categorias do cardápio e menu mobile.
- `assets/logo.jpg`: logo original usada no site.
